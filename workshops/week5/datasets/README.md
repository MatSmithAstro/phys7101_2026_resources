## `lancaster_quay_tidal.csv`

An identical copy of the Week 1 file, so each week's folder is self-contained. Source, dates, attribution and how to refresh it: see `workshops/week1/datasets/README.md`.

All other signals in the Week 5 lab are simulated inside the notebook, with fixed seeds, so every student gets the same numbers.
